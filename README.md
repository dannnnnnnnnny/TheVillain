# Villain

낯선 도시에서 깨어난 주인공이 귀환 신호를 따라가는 픽셀 액션 게임입니다. 거대한 지구 지도와 평화로운 포르투의 일상으로 시작하고, 긴급 뉴스가 같은 장면을 전혀 다른 시선으로 보여 줍니다. 독자적인 슈퍼히어로 코믹 패널, 굵은 잉크 테두리, 픽셀 하프톤과 빨강·노랑·보라 강조를 적용했습니다. 실제 전투 사건 캡처, 군대와 수호자, 공포 성장과 저장을 유지합니다.

Node.js 22 이상이 필요합니다. 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)을 열면 커다란 픽셀 세계지도가 나옵니다. 눈에 띄는 **첫 침공 시작 · 포르투** 버튼, 아래 화살표가 가리키는 **포르투갈** 표식 또는 실제 국가 영역을 클릭하세요. 세 경로 모두 같은 포르투갈 전용 선택 규칙을 사용합니다. 포르투갈만 선택 가능하며, 다른 국가는 공포가 올라가도 잠겨 있습니다. 표식은 키보드 Tab / Enter로도 선택할 수 있습니다.

평화로운 포르투에서 서로 사진을 찍는 시민과 관광객을 본 뒤, 기억을 잃은 주인공의 1인칭 독백과 귀환 신호를 읽습니다. 클레리구스 탑과 포르투 시청사 아래의 두 봉인이 집으로 돌아갈 균열을 막고 있습니다. **이야기 계속 / 이야기 건너뛰기 / Enter**로 앵커의 대피 방송을 엽니다. 앵커는 포르투 상공으로 괴생명체가 접근하고 있으니 즉시 안전한 곳으로 대피하라고 알립니다. 뉴스 속 괴생명체가 자신임을 깨닫는 독백은 이 방송에서 처음 나타납니다. 방송의 **현장으로 / 이야기 건너뛰기 / Enter**로 전투에 진입합니다. 두 동작은 분리된 버튼으로, 좁은 화면에서는 세로로 놓입니다. 프롤로그와 방송 중 전투·작전 시간·스킬은 정지하고 이전 입력은 전투에 이어지지 않습니다. 결과에서 재도전하면 대피 방송으로 바로 이동하며 **세계지도**로 돌아가 포르투갈을 선택하면 프롤로그를 다시 볼 수 있습니다. 포트는 `PORT=5180 npm start`로 바꿀 수 있습니다. 서버는 로컬 루프백에만 연결합니다.

지도는 로컬 Natural Earth 국가 GeoJSON을 낮은 해상도로 렌더링해 확대합니다. 국가 경계와 실제 포르투 위치를 유지하며, 지도는 로드·크기 변경 시에만 다시 그립니다. 데이터 로드 실패 시 **지도 다시 불러오기** 또는 포르투갈 표식으로 계속할 수 있습니다. 그림 로드 실패 시 설명과 진행 버튼이 남습니다.

| 조작 | 행동 |
|---|---|
| 땅 우클릭 | 해당 지점까지 이동 후 정지; 건물을 우회하며 물/도시 밖은 선택 불가 |
| 대상 우클릭 / 대상에 커서를 올리고 A | 살아 있는 단일 건물/군대/수호자에게 접근 후 자동 평타; 빈 땅의 A는 무시 |
| 방향키 | 화면 방향 보조 이동; 기존 이동/공격 명령 취소 |
| 마우스 | 스킬 방향/대상 선택; 대상을 강조 표시 |
| Q | 지옥의 숨결: 누르면 준비 0.16초 후 커서를 따라 정지 분사. 길게 최대 2초, 짧게 눌러도 최소 0.25초. 기력 8 + 초당 14, 재사용 4초 |
| W 누르기 | 정지하고 커서 방향 방어; 붙잡기는 막지 못함 |
| E | 커서 방향 돌진, 지나간 경로의 대상만 한 번씩 공격; 기력 25, 재사용 5초 |
| R | 파멸 광선: 커서 방향으로 0.55초 조준 충전 후 즉시 관통 발사(평타 9배), 사거리 760. 발사 순간 방향 고정. 기력 45, 재사용 12초. 빈 곳에도 발사하며 충전 취소 시 소모는 유지 |
| Space | 짧은 무적 회피; 기력 18 |
| 붙잡힌 상태에서 E 여섯 번 | 탈출; 키 자동 반복은 세지 않음 |
| 방송에서 Enter | 시작 방송 건너뛰기 / 종료 방송에서 작전 결과로 이동 |
| Escape | 정지 / 재개; 명령과 누른 입력을 취소 |

전투 왼쪽 상단과 오른쪽 설명에 표시된 귀환 봉인을 풀려면 **클레리구스 탑**과 **포르투 시청사**를 무너뜨려야 합니다. 시민들이 보는 것은 두 랜드마크의 붕괴입니다. 두 목표를 모두 파괴하면 수호자가 살아 있어도 즉시 성공합니다. 랜드마크의 지붕/벽에 우클릭하거나 커서를 올리고 A를 누르면 건물을 피해서 접근한 뒤 해당 목표만 자동 공격합니다. 초록 표식은 이동 목적지입니다. Q는 분사 중에도 커서 방향을 따라갑니다. E는 누른 순간의 커서 방향, R은 0.55초 충전하는 동안 조준하다가 발사 순간 방향을 고정합니다. Q/R 중에는 정지합니다. W는 이동과 자동 평타를 취소하고 정지 방어합니다. UI 포커스/클릭, 정지, 창 이탈은 진행 중 명령까지 취소합니다. 오른쪽 아래 지도가 목표 위치와 플레이어를 표시합니다. 수호자의 공격 예고를 보고 회피하고, 빨리 접근하려면 돌진을 섞으세요. HP가 0이 되면 실패합니다. 제한 시간은 없습니다.

평타는 준비·휘두르기·타격·회복을 거치며 시작 후 0.12초에 실제 피해를 줍니다. Q는 0.1초 간격으로 전방 부채꼴에 초당 평타 3배 피해를 주고, R은 직선 경로의 각 대상을 한 번씩 관통합니다. 이동·방어·회피·새 이동 명령·정지는 채널/충전을 취소합니다. E는 0.07초 준비 후 실제 돌진 접촉 때 피해를 주며 건물 벽을 통과하지 않습니다. 전용 포즈 시트와 흰 중심/주황/보라 불꽃, W 장막, E 실제 캐릭터 잔상, R 전기/광선/반동이 적용됩니다. 짧은 히트 스톱 중 누른 Q/R은 바쁜 동작이 끝난 뒤 한 번 처리하며, 취소·정지·화면 복귀 시 버립니다. 효과는 최대 128개이며 수명이 지나면 정리합니다.

루멘은 주먹 준비·타격·회복, 0.22초 연속 비행 돌진, 붙잡기, 피격 전용 포즈를 사용합니다. 돌진은 예고한 방향으로 최대 190만큼 이동하며 경로 접촉에서 한 번만 피해를 주고 회피 무적을 보존합니다. 붙잡기 E 6회 탈출 시 연결이 끊어지고 루멘이 뒤로 밀려납니다. 각성 시 금빛/청록 불티를 두릅니다.

사건 뉴스의 주 사진은 해당 사건 당시의 실제 전장 캡처입니다. 별도 시민 인터뷰는 사건 종류에 맞는 두려움/절망 이미지와 짧은 극중 대사를 더하며, **극중 시민 인터뷰 · 재구성**으로 표시합니다. 실제 사상자 수를 추정하거나 발명하지 않습니다.

전투가 끝나면 작전 결과 전에 앵커가 실제 종료 전장과 피해 수치를 보도합니다. 전체 건물 중 **80% 이상이 실제 붕괴**한 경우 통신 두절 화면 뒤에 피해자를 안은 생존자·구조 인력의 픽셀 일러스트를 보여줍니다. 이 이미지는 **현장 재구성**으로 표시하고 실제 종료 전장 캡처를 별도로 유지합니다. 그보다 피해가 적은 성공은 파괴한 주요 지구만 보도하며, 실패는 괴생명체 활동 중단과 남은 피해를 보도합니다. 기존 사건별 기사 사진은 각 사건 당시 실제 캡처입니다. 엔딩은 항상 건너뛸 수 있습니다.

성공은 공포 +40(최대 160)을 한 번 지급합니다. 공포 40 / 100에서 진화하며 HP는 600 / 820 / 1100, 방어는 0 / 12 / 24%입니다. 크기, 외형, 공격력과 범위가 함께 성장합니다. 높은 공포에서는 수호자도 강해집니다. 실패는 공포를 지급하지 않습니다.

공포만 이 브라우저의 `localStorage` 키 `villain.fear.v1`에 저장합니다. 손상되거나 차단된 저장소에서도 플레이할 수 있으며, 저장이 차단되면 현재 탭에서만 진행을 유지합니다. **진행 초기화**는 확인 후 이 게임의 저장 키만 삭제합니다. 세계지도 복귀는 진행 중 작전을 종료합니다. 탭 이탈/창 비활성화는 자동 정지하며, 복귀 후 직접 재개하세요. 음향은 기본 꺼짐이며 상단 버튼으로 켭니다.

```sh
npm test
```

Node 내장 테스트가 전투·승패·보상·공포 경계·저장 실패·입력·사건 스냅샷·뉴스를 확인합니다. 시뮬레이션은 브라우저 API 없이 독립 실행됩니다. Canvas 렌더러가 시뮬레이션을 그리고, 앱이 입력·캡처·저장·음향을 연결합니다. 각 뉴스는 해당 사건이 발생한 순간의 독립 장면을 렌더링한 이미지입니다.

PC 키보드/마우스 우선 프로토타입입니다. 빌런 1종, 추상화한 포르투 구역 1개, 목표 2개, 수호자 1종을 포함합니다. 실측 지도가 아니며 다른 도시/계정/온라인 기능/실시간 생성형 뉴스는 없습니다. 악마 스프라이트는 생성형 이미지 자산이며 도시·전투·파괴는 실제 게임 상태를 그립니다. 스프라이트가 로드되지 않으면 코드로 그린 픽셀 악마를 표시합니다.

공격 모션에는 MIT 라이선스의 `tweenjs/tween.js` Easing.ts에서 가져온 quadraticIn / cubicOut / backOut / elasticOut을 실제 보간에 사용합니다. 출처 커밋은 `84a27a74febbda783eebb7ee3e7d7c7abfd25009`이며, 원문 허가문과 수정 범위는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다. 런타임 외부 의존성은 없습니다. 평화로운 포르투 프롤로그·앵커·현장 재구성 이미지는 생성형 자산이며, 시작·종료·사건 전장 이미지는 게임 상태에서 직접 렌더링합니다. 전투 목표는 전장 왼쪽 상단, 사건 뉴스는 오른쪽의 넓은 패널에 표시됩니다.
